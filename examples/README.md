# Examples <!-- omit in toc -->

These case studies show the Dev0 methodology in practice. They break down real architectural decisions against the six core tests: **less**, **separate**, **legibility**, **native**, **beneficiary**, and **control**.

Each example follows a strict format: the context, the industry's default bloated approach, the zero-based Dev0 alternative, the specific tests applied, the final outcome, and the accepted trade-offs. I will add new examples here as I build them out.
